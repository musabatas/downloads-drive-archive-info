Downloads Drive Archive

Privacy policy

Effective October 17, 2026. This application is a personal utility operated locally by its sole user.

Data accessed and purpose

The utility reads completed files and file metadata within the local Downloads folder, uploads them to the user's Google Drive, and reads Drive file metadata and checksums to verify transfers. It reads the signed-in account's email address to confirm that the destination is the intended account.

Storage and sharing

File contents are transmitted directly from the user's Mac to Google Drive using rclone. Google processes the data under its own applicable terms and privacy policy. No separate application server receives the files. The utility does not sell data, share it with advertising or analytics services, or use it to train AI models.

OAuth credentials are stored locally with owner-only file permissions outside the Downloads folder. Local verification records store hashed file identifiers, file fingerprints, and verification times. Routine utility logs contain aggregate counts and status information.

Retention and control

Local files are retained for at least seven days after their first verified upload; modification restarts this period. Eligible local files are removed only after the Drive copy is checked again. Archived Drive files and previous versions remain until the user removes them. Disabling the macOS scheduled job stops future processing.

The user can revoke access through Google Account connections and can remove archived files directly in Google Drive. Revoking access does not automatically delete existing archives.

Limited use

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

The developer support address is provided on the Google OAuth consent screen. The sole user is also the operator of the utility.
